## 🐍 Python Mini Projects for Practice

This repository contains **small Python mini projects** created to improve **basic programming logic and problem-solving skills**.
These projects are especially helpful for **beginners** who want hands-on practice with core Python concepts like conditionals, loops, functions, and user input.

---

## 📂 Project List & Overview

### 1️⃣ ATM Machine (`atm_machine.py`)

A simple ATM simulation that allows users to:

* Check balance
* Withdraw money
* Deposit money
* Exit the system

**Concepts used:** Conditions, loops, functions

---

### 2️⃣ Dice Rolling Simulator (`dice_rooling.py`)

Simulates rolling a dice and generates random numbers between 1 and 6.

**Concepts used:** Random module, loops

---

### 3️⃣ Password Strength Checker (`passwored_strength_cheaker.py`)

Checks whether a password is **weak, medium, or strong** based on:

* Length
* Use of digits
* Special characters

**Concepts used:** Strings, conditions

---

### 4️⃣ Quiz Game (`quiz_qame.py`)

A console-based quiz game where users answer questions and get a final score.

**Concepts used:** Dictionaries, loops, conditions

---

### 5️⃣ Random Number Guessing Game (`random_number_guess.py`)

The computer generates a random number, and the user tries to guess it.

**Concepts used:** Random numbers, loops, user input

---

### 6️⃣ Rock Paper Scissors – Using Functions (`rock_paer_scissor_using_function.py`)

A Rock-Paper-Scissors game implemented using functions for better structure.

**Concepts used:** Functions, conditions

---

### 7️⃣ Rock Paper Scissors – Basic Version (`rock_paper_scissinor.py`)

A simple version of the Rock-Paper-Scissors game without functions.

**Concepts used:** Conditions, user input

---

### 8️⃣ To-Do List (`todo_list.py`)

A basic command-line To-Do List application where users can:

* Add tasks
* View tasks
* Remove tasks


### Banking System (`banking_system.py`)

A basic Banking system to pratic to the Little Comple Logic of the python

* Create account

### BMI Calculator (`bmi_calculation.py`)

A basic simple python program that is uses to calculate the Real time BMI using the Height and Weight.

A simple project that is build using the simple python code for the `Registration and Login`.
